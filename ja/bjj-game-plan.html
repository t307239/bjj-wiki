BJJゲームプランの開発

BJJ Wiki · Updated 2026-03-16

ゲームプランはあなたのパーソナルBJJシステムです — プレッシャー下で確実に実行できるほど深く理解した特定のポジション・サブミッション・トランジション。ゲームプランを開発することで、反応的なグラップラーから対戦相手に関わらず自分の意志を押しつける積極的なグラップラーへと変わります。

目次

    ゲームプランとは何か？

    ゲームプランは論理的なチェーンを形成する深く理解された小さなテクニックセットです：エントリー → 支配的なポジション → フィニッシュセットアップ → フィニッシュ。ゴードン・ライアンのシステムはテイクダウン → バックテイク → リアネイキッドチョークをチェーンします。マルセロ・ガルシアのシステムはアンダーフックレスリング → Xガード → スイープまたはバックテイク → ギロチンまたはRNCをチェーンします。

    Aゲームの選択

    Aゲームはあなたのアスレチックプロフィールと本当に自分を興奮させるものから生まれるべきです。より長い四肢の実践者はしばしばトライアングルセットアップを好みます。爆発的でアスレチックなグラップラーはしばしばレスリングベースのプレッシャーパスで成功します。柔軟な実践者はディープガードシステムを開発します。

    💡 ゴードン・ライアンの原則: 「すべてのシナリオに機能する一つのことを持て。」目標はすべてのテクニックを持つことではありません — 基本的なグラップリングの各問題への一つの優れた答えを持つことです：テイクダウン・ガードパス・バックテイク・フィニッシュ。

    チェーンの構築

    チェーンをフローチャートとして設計してください：テイクダウンは何ですか？ → 相手がガードを引いたら？ → 相手のガードで何をしますか？ → パスしたら何が起きますか？ → 支配的なポジションのフィニッシュは何ですか？各リンクを意図的にマッピングしてください。各ギャップはトレーニングの優先事項です。

    プレッシャー下でのドリリング

    テクニックはレジスタンス下で機能する時のみゲームプランコンポーネントになります。ポジショナルスパーリング（30分間毎ラウンドあなたのガードセットアップから開始）は、テクニックのレジスタンステスト版を構築します。
