🕷️ Ataques da Guarda Aranha no BJJ

Domine a guarda aranha no BJJ: combinações de lasso, setups de triângulo, varridas e por que a guarda aranha é uma das melhores guardas específicas do gi.

Conteúdo

    Fundamentos da Guarda Aranha

    A guarda aranha usa grips de manga com controle do pé no bíceps para criar uma teia de tensão que controla a postura e posição dos braços do oponente. É exclusivamente uma técnica de gi e uma das guardas mais eficazes para lutadores menores contra oponentes maiores.

    Ataques da Guarda Aranha

    AtaqueTipoSetup
    Triângulo da AranhaSubmissionEstender um empurrão de bíceps, balançar perna para triângulo
    Omoplata da AranhaSubmissionEmpurrar bíceps distante, balançar perna externa para shoulder lock
    Varrida LassoVarridaLasso o braço, puxar para baixo + empurrão de perna para varrer
    Technical Lift SweepVarridaAmbos controles de bíceps + gancho borboleta = levantar

    Combinação Aranha para Lasso

    Aranha e lasso são guardas complementares que fluem uma para a outra. Quando posturam contra aranha, transitar para lasso no lado próximo. Quando defendem lasso, os empurrões de aranha criam entradas de triângulo.

    Defesa da Guarda Aranha

    ⚠️ Contra: Remova grips de manga imediatamente — se não conseguir, stack o corpo deles para reduzir flexibilidade, ou leg drag a perna próxima para passar antes que estabeleçam ambos os controles de bíceps.

    Perguntas Frequentes

    A guarda aranha é apenas para o gi?
    Sim — a guarda aranha requer grips de manga para funcionar. Não existe equivalente no-gi eficaz. No no-gi, a guarda borboleta e DLR fornecem controle similar sem grips de tecido.
    Como atacar o triângulo da guarda aranha?
    Com ambos os pés nos bíceps, estenda um bíceps com força para quebrar a postura, depois balance essa mesma perna pelo corpo deles para o triângulo enquanto mantém o outro controle de bíceps.
    Como passar a guarda aranha?
    Remova grips de manga (pegar a manga no antebraço, quebrar para fora), depois transitar para em pé. Uma vez quebrados os grips, leg drag ou torreando pela guarda aberta resultante.
