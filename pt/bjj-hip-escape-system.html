    O Que É um Hip Escape?

    Um hip escape é um movimento lateral do quadril que cria espaço entre você e o jogador de cima. Empurrando do chão e direcionando os quadris lateralmente (shrimping), você pode recuperar a guarda ou criar ângulos para ataques de baixo.

    As Três Variações de Shrimp

    Shrimp Lateral

    A versão mais comum. O quadril move diretamente para o lado — usado para recuperar a guarda quando o jogador de cima tenta passar.

    Shrimp para Trás

    O quadril move para trás e para o lado — usado para criar distância de um jogador de cima que pressiona.

    Sit-Up Shrimp (Granby Roll)

    Combina um sit-up com um hip escape — cria ângulo para ataques de guarda enquanto cria espaço.

    ⚡ Dica Pro: Faça shrimp ANTES de precisar, não depois que a guarda já foi passada. O shrimping proativo é muito mais eficaz do que o reativo.

    Perguntas Frequentes

    O que é shrimping no BJJ?

    Shrimping é um movimento lateral do quadril onde você faz uma ponte e depois direciona os quadris para o lado para criar espaço. É o movimento fundamental de escape no BJJ.

    Mais Perguntas

    Q: Por que meu pescoço dói quando tento fazer o shrimping no Jiu Jitsu para escapar da montada?

    A dor no pescoço ao fazer shrimping geralmente ocorre quando você usa o pescoço para empurrar o chão em vez de usar a força dos seus quadris e pernas. Para corrigir, mantenha o pescoço relaxado e concentre-se em impulsionar o quadril para longe do oponente, usando a sola do pé que está no chão como ponto de apoio para gerar o movimento.

    Q: Como posso fazer o shrimping para escapar da montada contra um oponente maior e mais forte no BJJ?

    Contra um oponente maior, a chave é usar a alavancagem e o timing. Em vez de tentar empurrar o peso dele diretamente, abaixe seu centro de gravidade e use o movimento do quadril para criar espaço. Concentre-se em mover seus quadris para o lado com um movimento explosivo, usando a sola do seu pé como um ponto de pivô para se afastar, em vez de tentar levantar o oponente.

    Q: Qual a melhor forma de posicionar minhas mãos e pés para executar um shrimping eficaz e escapar da guarda fechada no Jiu Jitsu?

    Para um shrimping eficaz na guarda fechada, posicione as mãos no chão, ligeiramente à frente dos ombros, com os dedos apontando para frente para criar uma base estável. Seus pés devem estar plantados no chão, com os calcanhares próximos aos glúteos, permitindo que você use a força das pernas e quadris para impulsionar seu corpo para trás e para o lado, criando a distância necessária para escapar.
