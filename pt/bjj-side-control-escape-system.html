    Mais Perguntas

    Qual a primeira coisa que devo fazer para escapar do controle lateral?

    A primeira coisa é tentar criar espaço, geralmente usando o joelho ou o quadril para afastar o oponente. Isso te dá a chance de começar a reestabelecer a guarda.

    Como posso usar meu quadril para escapar do controle lateral?

    Você pode usar o movimento de 'hip escape' (ou 'shrimping') para criar distância. Ao empurrar seu quadril para longe do oponente, você abre espaço para tentar trazer seus joelhos de volta para a posição de guarda.

    O que fazer se o oponente estiver com um bom controle e eu não conseguir criar espaço?

    Se o controle for muito forte, foque em defender a passagem de guarda e esperar uma oportunidade. Tente manter a calma, proteger seu pescoço e braços, e procure por pequenas aberturas para tentar reverter a posição.

    Perguntas Frequentes

    Q: Por que meu pescoço dói tanto quando o oponente está no controle lateral e eu tento sair?

    Essa dor geralmente ocorre quando você tenta 'levantar' o corpo com o pescoço para criar espaço, em vez de usar a força do quadril e das pernas. Ao invés disso, concentre-se em 'desencaixar' o quadril do oponente, usando o joelho da perna mais próxima para criar uma cunha entre seus corpos e empurrar o quadril dele para longe.

    Q: Como posso usar o escape lateral quando meu oponente é muito maior e mais forte que eu?

    Contra um oponente maior, a chave é a alavancagem e o uso do chão. Em vez de tentar empurrar o peso dele diretamente, use seu quadril para 'deslizar' para fora da base dele, criando um ângulo. Simultaneamente, use o peso do seu corpo e o braço que está mais livre para empurrar a perna dele para longe, abrindo espaço para você se mover.

    Q: Qual a melhor forma de escapar do controle lateral se o oponente está com o braço por baixo do meu pescoço?

    Quando o braço do oponente está bloqueando seu pescoço, o objetivo é criar espaço para que ele precise mover o braço. Use a mão livre para empurrar o quadril dele, enquanto simultaneamente 'desencaixa' o seu próprio quadril para longe do dele. Isso força o oponente a reposicionar o braço, abrindo uma janela para você tentar o 'shrimp' (movimento de camarão).
