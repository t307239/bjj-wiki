📋 Sistema de Pontuação do BJJ Explicado

Entender o sistema de pontuação do BJJ é essencial para o sucesso competitivo. Pontos recompensam dominância posicional; vantagens servem como desempate. Finalizações vencem independentemente do placar.

Conteúdo

    Valores de Pontos IBJJF

    AçãoPontosRequisitos
    Queda2Levar adversário ao chão, posição de cima por 3 seg
    Joelho na barriga2Joelho no estômago, outra perna estendida, 3 seg
    Passagem de guarda3Limpar pernas e estabelecer lateral/norte-sul por 3 seg
    Raspagem2Reverter de baixo para cima, 3 seg
    Monte4Ambos joelhos no chão ao lado do torso, 3 seg
    Controle de costas4Ambos os ganchos ou cinto, 3 seg

    Vantagens

    SituaçãoVantagem Concedida
    Quase finalização (tap não obtido)1 vantagem
    Quase passagem (não mantida 3 seg)1 vantagem
    Quase queda1 vantagem
    Quase monte/costas1 vantagem
    Ordem de desempate: 1. Pontos → 2. Vantagens → 3. Punições → 4. Decisão do árbitro
    Dica Pro: Em lutas disputadas, o acúmulo de vantagens frequentemente decide o vencedor. Treinar para ameaçar finalizações — mesmo sem finalizar — gera vantagens que vencem lutas.
