Uma varrida marca 2 pontos e reverte a posição — mas mais importante, dá controle de cima. Entender a mecânica do desequilíbrio e timing é a chave para varrer em todos os níveis.

As Três Direções de Desequilíbrio

  • Para frente (para joelhos): Puxe gola + quebre postura para frente. Configura hip bump, guilhotina.
  • Para os lados: Empurre/puxe manga + desequilibre para esquerda ou direita. Configura scissor, varridas lasso.
  • Para trás (acima da cabeça): Ambos os pés nos quadris, empurre para cima. Configura overhead, flower sweep.

Dicas de Timing de Varridas

  • Varra na direção do peso do jogador de cima — nunca contra.
  • O melhor momento para varrer é imediatamente após ele apoiar uma mão (menos base).
  • Combine ameaças de ataque: ameace uma finalização primeiro, então varra quando defender.

Perguntas Frequentes

O que é uma varrida no BJJ?
Uma varrida é uma técnica onde o jogador de guarda reverte a posição para ficar em cima. Varridas marcam 2 pontos na competição IBJJF quando a reversão é alcançada.
O que faz uma varrida funcionar?
O desequilíbrio é a chave. Você deve quebrar a base do jogador de cima primeiro, depois usar o mecanismo da varrida. Uma varrida tentada sem primeiro perturbar o equilíbrio quase sempre falhará.
Qual é a varrida mais fácil no BJJ?
A scissor sweep da guarda fechada é frequentemente a primeira ensinada — usa grip gola-manga, chuta uma perna para fora e uma tesoura para reverter a posição.
