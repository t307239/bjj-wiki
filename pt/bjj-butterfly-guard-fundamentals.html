🦋 Fundamentos da Guarda Borboleta no BJJ

Domine a guarda borboleta no BJJ: posicionamento de ganchos, body lock, elevator sweep, seatbelt e entradas de costas.

A guarda borboleta é uma guarda sentada usando ganchos internos em ambas as pernas. É uma das guardas no-gi mais eficazes e transita naturalmente para varridas com body lock, tomadas de costas e ataques de perna simples.

Conteúdo

    Configuração da Guarda Borboleta

    • Sente próximo ao oponente — não recue.
    • Insira ambos os ganchos dentro das pernas do oponente.
    • Lute pelo underhook — é o grip chave para varridas e tomadas de costas.
    • Mantenha collar tie ou controle da cabeça firme para impedi-lo de melhorar a postura.

    Ataques da Guarda Borboleta

    AtaqueTipoPreparação Chave
    Elevator sweepVarridaUnderhook + cair para o lado
    Body lock sweepVarridaGancho dois-em-um + body lock
    Tomada de costasTransiçãoUnderhook + push to sit
    Arm dragTransiçãoDois-em-um para exposição das costas

    Passagem da Guarda Borboleta

    • Passe a guarda borboleta removendo um gancho de cada vez — não ambos simultaneamente.
    • Stack e smash: avance, achate os ganchos.
    • Sit through: passe por cima de um gancho, smash o outro para meia guarda.

    Perguntas Frequentes

    O que é a guarda borboleta no BJJ?
    A guarda borboleta é uma guarda sentada onde ambos os pés são colocados dentro das pernas do oponente como ganchos. Os ganchos criam uma plataforma de elevação para varridas e controle para tomadas de costas.
    A guarda borboleta é melhor no gi ou no-gi?
    É altamente eficaz em ambos, mas é especialmente popular no no-gi porque não depende de grips — usa posicionamento corporal e ganchos internos.
    O que é a butterfly sweep?
    A butterfly sweep (elevator sweep) usa um gancho para elevar a perna do oponente enquanto cai para o mesmo lado e usa um underhook para rolá-lo.
