    Perguntas Frequentes

    O que são 'frames' no Jiu Jitsu e por que são importantes?

    Frames, ou quadros, são extensões do seu corpo (geralmente braços e pernas) usadas para criar espaço e impedir que seu oponente se aproxime demais ou passe sua guarda. Eles são cruciais para manter a distância e controlar a posição, sendo a base da defesa no Jiu Jitsu.

    Como posso usar meus braços para criar um 'frame' eficaz contra um ataque?

    Para criar um frame com os braços, estenda-os firmemente com os cotovelos ligeiramente flexionados, empurrando contra o corpo ou ombros do oponente. O objetivo é criar uma barreira sólida que o impeça de avançar e te incomode se ele tentar te empurrar.

    Além dos braços, quais outras partes do corpo posso usar para criar 'frames' defensivos?

    Você pode usar suas pernas para criar frames, especialmente quando está na guarda fechada ou aberta, estendendo-as para manter o oponente afastado. Seus quadris também podem ser usados para criar um frame, empurrando para cima ou para o lado para gerar espaço e se reposicionar.
