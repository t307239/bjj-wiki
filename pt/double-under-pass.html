    Mais Perguntas

    Como eu evito que meu oponente me passe com o double under?

    Para evitar o double under, mantenha a base baixa e larga, use seus quadris para criar pressão contra o oponente e tente manter os joelhos afastados. Se ele conseguir fechar os braços, tente criar espaço com os cotovelos ou um quadril.

    Qual a melhor forma de finalizar o double under pass para obter a montada ou as costas?

    Após controlar os braços com o double under, você pode usar a pressão do seu corpo para empurrar os quadris do oponente para o lado, abrindo caminho para a montada. Alternativamente, se ele tentar defender de costas, você pode usar a pegada nos braços para girar e buscar as costas.

    O que fazer se meu oponente defender o double under pass com um 'guard retention' forte?

    Se o oponente usar um bom 'guard retention', como um 'knee shield' ou 'half guard', você precisará ajustar sua pressão e ângulo. Tente usar o peso do seu corpo para quebrar a defesa, ou procure transições para outras posições de passe, como o 'over-under' ou 'torre'.
